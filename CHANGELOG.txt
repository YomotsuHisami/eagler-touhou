EAGLER TOUHOU CHANGELOG
=======================

[2026-08-18] HTTPS、触控与稳定性更新

功能更新

- HTTPS 与数据迁移：推荐使用 https://touhou.vip/eagler-touhou/ ，并可将旧 HTTP 站的 TH06 / TH07 存档、Replay、网页设置和已保存的本地游戏数据迁移到 HTTPS。
- 本地游戏数据：支持手动导入 TH06 / TH07 数据 ZIP；本地数据与 Web runtime 独立更新，已导入的数据和 OGG 不会因网站更新被强制作废。
- 手机操控：新增「触摸」「触摸（作弊，不限速）」「轮盘」「轮盘（无方向限制）」四种移动方式，并提供可选的双击 Bomb。
- 触控布局：新增可编辑的触控按键布局，TH06 / TH07 共用，横屏和竖屏分别保存。
- 屏幕操作：新增实验性的放大镜与游戏内横/竖屏切换；关闭放大镜会恢复原始 100% 画面位置。
- thprac：继续完善连续 Practice 的状态处理，并新增默认关闭的移动端 thprac 按键，可通过鼠标模拟、Backspace 与 F1–F7 操作 Mod Menu。

Bug 修复

- 修复了移动端在缩放、全屏、退出全屏或返回菜单后，当前网页偶尔无法正常滑动、轻点失效或需要异常长按的问题。
- 修正了锁定 60 帧时仍使用高刷新率残余插值的问题，减少非 60Hz 屏幕上的额外抖动。
- 修复了 TH07 Music Room 中文说明在还没有显示到对话框右侧时就被提前截断，以及标题/第一行显示位置异常的问题。
- 修复了 TH07 Demonstration 与 Ending 中额外的画面闪烁问题。
- 修复了普通窗口下游戏 4:3 画面可能按宽度放大后超出窗口下边缘的问题。
- 修复了部分 Android 浏览器中蓝牙键盘方向键与 ESC 无法正常输入的问题，包含 Via 浏览器将方向键暴露为 Gamepad、ESC 只发送 keyup 的情况。

[2026-08-17] 功能与稳定性更新

功能更新

- 适配「thprac」，TH06 / TH07 现支持练习选段、符卡练习、Replay、Mod Menu 等主要功能。
- 适配「thcrap」的大多数语言包；默认提供「日本語 → 中文（简体）→ English」，网页只显示服务器实际提供的语言。
- 根据反馈，在「手机适配」中新增三个「低速方法」：双指、按钮（按住时低速）、按钮（按下时切换状态）；按钮模式会在「开火」上方显示「低速」按钮并停用游戏中的双指低速，菜单双指返回保持不变。
- 触控帮助新增横屏与全屏操作图示，并在本次更新后重新提醒所有使用触控的玩家一次。
- 将「翻译」与「thprac」整理进「实验性功能」，并支持服务器分别决定是否提供这些功能。
- 电脑端「锁定 60 帧」增加红色提示：如果帧数在游玩时经常严重波动，那么必须启用该选项，否则会造成严重的输入延迟。

Bug 修复

- 修复了「TH06 子弹明显抖动」的问题，是因为 GLES 错误走了软件顶点处理路径，子弹坐标被逐帧取整。
- 修复了「公网页面无法启用翻译」的问题，是因为网页对语言包进行了不必要的哈希校验。
- 修复了「TH06 咲夜时间停止时画面抽搐、杀人玩偶飞刀异常旋转」的问题，是因为冻结对象的渲染插值状态没有同步。
- 修复了「TH06 Result / Replay 保存背景偶尔出现斜向渐变」的问题，是因为 2D 背景拷贝错误继承了上一场游戏的雾效状态。

[2026-08-15] 稳定性更新

功能更新

- 新增「更新日志」入口；每个新版本只会自动显示一次，之后仍可手动查看。
- 新增「锁定 60 帧」选项：电脑端可自行选择，移动端暂时强制启用，以减少浏览器高刷新率调度造成的严重帧率波动。

Bug 修复

- 修复了「松开第二根手指后仍持续低速，甚至无法移动」的问题，是因为触控角色状态可能在抬手、取消或跨状态切换后没有释放。
- 修复了「ESC 菜单双指操作后，后续点击和滑动全部失效」的问题，是因为双指菜单手势可能一直残留在活动状态。
- 修复了「更新后浏览器可能混用新旧 Web 运行时文件」的问题，是因为运行时文件的缓存版本没有完全绑定到同一代构建。
