## 遇到 游戏闪退 / 卡顿 / 黑屏 / 加载异常 / 断触 等问题怎么办？

推荐优先使用以下浏览器：

- **Android**：[Edge](https://www.microsoft.com/edge/download) / [Chrome](https://www.google.com/chrome/)，请使用最新版本，不建议使用 Via。华为设备不要使用卓易通或 Via，可以尝试系统浏览器。

    **其他 Android 设备不建议使用系统自带浏览器和各种国内浏览器。你也可以用，但可能会有一定的 BUG，如目前已知夸克浏览器会断触。**

- **Windows**：Edge（系统自带） / [Chrome](https://google.cn/chrome) / [FireFox](https://www.firefox.com/)
- 如果您在使用 Windows 7 及以下的版本，请使用[Supermium](https://www.supermium.net/) 作为上述浏览器的替代。
- 苹果：随意

若使用以上任一浏览器却仍然遇到了问题，再与我们反馈。

若旧版浏览器无法进入首页，或 WebGL 2.0 检测失败，请先查看[设备与浏览器兼容指南](compatibility.html)，其中包含 Supermium 安装和 Chrome OpenGL 后端设置步骤。

## 游戏可以“存档”吗？

STG游戏存档分两个概念。

- 一种是「一局中途停下，退出游戏，能在下一次打开游戏时继续以原先的残机等状态玩这一局吗？」。
  这个答案是：**不能**。因为：原版/所有的STG类游戏机制便是如此。不过，一局游戏平均下来也就 25 分钟左右，很快就能打完。

- 另一种是「我的游玩数据，比如通关记录、游玩时长等非游戏内状态数据，能保存下来吗？」
  这个答案是：**完全可以**。并且通过测试，和原版游戏互通，存档文件为：“score.dat”。

>  **注：不同游戏存档不能混用!** 如 th06 的 score.dat 不能在 th07 使用。

## 会有地灵殿等其他正作 / 小数点作 / 格斗作 / 二次创作 / 新典......吗？

对于*较旧的正作（th14之前）*，我们正在**尽力将其移植到网页端**。上线时间不定。

对于*较新的正作（th14及之后）/小数点作/格斗作*，我们**暂不考虑**（绀珠传和锦上京除外）。但是仍然作为我们的To-Do List中的一环。（注：即使移植了格斗作，我们也不能设置联机。如果可能有移植，那格斗作的复杂连招、极为严苛的搓招和大量的按键**导致格斗作人性化移植到移动端根本不可能**。）

对于*新典*，我们**不会移植**。因为版权风险太大，并且性价比不高。

对于*二次创作*，我们**尽力将其移植到网页端**。目前正在对弹幕风、海鲜堂等二次创作游戏进行适配。

## 下载不了资源怎么办？

首先，确认**没有使用 VPN**。

其次请避免使用会接管网页下载的浏览器插件，目前已确认 Internet Download Manager 等插件可能与网页资源加载不兼容。

站点成功打开过一次后，即使 服务器随后不可用 或者 你断网了，刷新或重新打开页面也可以进入启动器（较新的浏览器几乎都支持）。

实在无法下载的话，就请使用导入包了。

## 网络联机问题

> 这一栏需要考虑被移除。

网络联机使用了P2P（Peer to Peer，点对点）和中转服务器回退混合的联机技术。

联机前，请先确认 **没有使用 VPN** 和双方的 **NAT类型**。测试方法：[猫点饭](https://mao.fan/mynat) 或 [NAT Checker](https://natchecker.com/)。如您不了解 NAT 类型为什么会影响联机，可以查看[百度百科](https://baike.baidu.com/item/%E7%BD%91%E7%BB%9C%E5%9C%B0%E5%9D%80%E8%BD%AC%E6%8D%A2/2985755)。

如果双方的NAT类型为“Full Cone(NAT1)/(Port) Restricted Cone(NAT2/NAT3)”，那么P2P连接就有**极大概率成功**，在网络信号良好的情况下大概率不会出现任何联机问题。

如果双方有**任何一方**的 NAT 类型为“Symmetric(NAT4)”，那么 P2P 连接就有**极大概率失败**。即使网络信号良好，也容易回退到中转服务器来保证联机的可用性。随之，联机的流畅程度便有很大可能下降。

通俗讲：只有双方NAT数值之和小于等于6，才*有机会*进行P2P网络联机。

为防止联机观战导致游戏问题，**联机对战窗口仅在开始前有效**。即：在开启房间之后，只有在开始游戏前的时间内才可以进入联机房间的观战窗口，游戏开始后无法进行观战（进入观战的观战者可以一直看到结束）。（观战仅th06/th07有效）
