
　キャラによってサイズや差分量などバラバラですので使い辛いかもしれません。

　psdファイルにて帽子、箒の着脱が出来ます。
　帽子を被らせる際は「帽子時on」レイヤーを表示しといて下さい。
　帽子単品のpsdファイルは、間に何か挟めば別のキャラとかに被らせたりできるかも。
