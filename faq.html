游戏闪退 / 卡顿 / 黑屏 / 加载异常 / 断触（夸克）等浏览器相关问题怎么办？

推荐优先使用以下浏览器：

Android：Via（仅 < 5 MB） / Edge / Chrome

Windows：Edge（系统自带） / Chrome

若使用以上任一浏览器却仍然遇到了问题，请与我们反馈。

会有永夜抄/风神录......（其他作品）/小数点/格斗作/二次创作......吗？

目前不会，因为这些作品的源代码反编译工作仍在进行。我们/几乎所有的 th06/07 衍生作品（多人联机啦、网页/手机移植啦......）都是基于已经反编译好的源代码进行的。没有完整且准确的反编译源代码，一切移植都是空谈。（目前老外们的反编译团队永夜抄反编译进度大约在 35%）

下载不了资源怎么办？

如果已经安装过游戏，服务器很慢或暂时离线时仍可直接启动本地版本；首次安装、更新或补充缺失资源时才需要等待服务器。

如果当前下载长时间没有进展，可以稍后重试，或使用页面提供的游戏包导入入口。请避免使用会接管网页下载的浏览器插件；目前已确认 Internet Download Manager 等插件可能与网页资源加载不兼容。

在支持 App Shell 离线恢复的环境中，站点成功打开过一次后，即使服务器随后不可用，刷新或重新打开页面也可以进入启动器。普通 HTTP 环境不支持 Service Worker 时，刷新页面仍然需要服务器可达。

关于格斗作的移植

目前，格斗作已明确“不会对其进行反编译”，这表明在很长一段时间里，格斗作的移植不会出现。

如果可能有移植，那格斗作的复杂连招、极为严苛的搓招和大量的按键导致格斗作人性化操作移植到移动端根本不可能，还不如直接用 Windows 兼容层模拟。
