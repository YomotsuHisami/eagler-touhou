EAGLER☯TOUHOU

一个东方 Project 官方作品的全作适配项目。
力求让每个人玩上东方原作。

目前已适配 TH06、TH07、TH08、TH09 与 TH10，并为桌面和移动设备提供网页运行与触控支持。高刷新率、汉化、thprac 与联机等扩展能力仅在对应作品明确声明支持时提供，具体以启动器中的作品说明为准。

贡献方式

您可以从 GitHub 仓库立刻开始参与贡献。

若要负责一部游戏的移植，请先阅读游戏适配指南与开发文档。若要修复问题或增加功能，可以提交 Issue，并通过 Pull Request 提交相应代码。
