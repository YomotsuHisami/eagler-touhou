电脑

Windows 7 及更早版本

  1. 下载并安装 Supermium（备用下载）。
  2. 使用 Chromium 108 或更新版本。
  3. 运行 WebGL 2.0 测试。通过后即可进入。

IE / 旧版 Chrome

Windows 10/11：安装最新版 Chrome 或 Edge。

旧版 Windows：安装左侧的 Supermium。

WebGL 2.0

更新驱动

  1. 安装最新显卡驱动并重启。
  2. 打开 chrome://settings/system，启用图形加速。
  3. 重启 Chrome，重新测试。

尝试 OpenGL

  1. 打开 chrome://flags/#use-angle。
  2. 选择 OpenGL，重启并测试。

没有该选项：关闭 Chrome，在快捷方式末尾添加 --use-angle=gl。
