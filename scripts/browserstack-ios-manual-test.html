TH07 iPhone DATA-only 手测

本测试包不含 OGG，只验证 Package 导入、Service Worker Runtime、游戏 DATA 和首帧。

步骤 1 - 下载无 OGG TH07 Package 步骤 2 - 打开 TH07 Launcher
  1. 先完成 ZIP 下载。
  2. 打开 Launcher，确认选择 TH07 和「无音乐」。
  3. 点击「导入」，在文件选择器中选择刚下载的 ZIP。
  4. 导入完成后点击「启动游戏」。
  5. 记录是否进入游戏首帧，以及是否出现「データファイルが存在しません」。

通过标准：进入游戏首帧，且没有 DATA 文件不存在错误。OGG 不在本轮验收范围。
